# CET6 Focus v1.5 Quality Hardening Evidence

This directory contains the implementation evidence for the approved v1.5 quality-hardening scope.

The browser fixtures are test-only. Each test starts from an isolated IndexedDB context, writes three deterministic active records, and leaves the runtime database and vocabulary unchanged. The screenshots are generated by `tests/e2e/readability/quality-hardening.spec.ts` for Chromium, Mobile, and WebKit Readability.

Scope covered:

- `P2-TYPO-001`: raise the two approved audio-control labels to 12px.
- `P2-A11Y-001`: keep the visible Settings import button as the sole semantic entry while removing the hidden file input from the tab sequence and accessibility tree.
- `P3-COVERAGE-001`: add deterministic non-empty Weak Words and Dictation fixture coverage, including the existing backup/import regression in the full suite.

See [`FINAL_V1_5_QUALITY_HARDENING_REPORT.md`](./FINAL_V1_5_QUALITY_HARDENING_REPORT.md) for the complete gate record and release boundary.
